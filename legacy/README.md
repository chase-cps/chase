# Legacy demos

The `demo` directory contains the demonstrations of the monolithic version of
CHASE, which was developed until 2022. Since then, CHASE has been split into
separate modules, and the source code of the monolithic version is available
on the `archived` branch and the `old_library` tag of this repository.

These demos are kept for reference only. They are not maintained and they may
not work with the current version of CHASE.

The demos of the current version of CHASE are in the [demos](../demos)
directory, which contains the [chase-cps/demos](https://github.com/chase-cps/demos)
repository.
